# 提示词模板服务模块（prompt_template）

## 模块职责

负责提示词可复用片段的增删改查管理。Agent 定义中的系统提示词通过引用片段的唯一描述名进行模板拼接。

## 存储

- 提示词片段以 YAML 文件存储在 `.spread-ai/prompt-snippets/` 目录下，支持子目录分类组织
- 文件名使用 UUID（如 `a3f1b2c4-5d6e-7f8a-9b0c-1d2e3f4a5b6c.yaml`），文件名不参与业务逻辑
- 每个片段文件内自声明唯一描述名（`name` 字段），启动时扫描目录自动建立 name → 文件 的映射索引
- name 重复时校验报错

## 片段文件格式

```yaml
name: 业务架构设计规则
text: |
  遵守以下架构设计规则：
  1. ...
  2. ...
```

## 核心能力

- **查询**：根据唯一描述名获取片段内容；列出所有已注册片段
- **新增**：创建片段文件并注册到索引
- **修改**：更新片段内容或描述名
- **删除**：删除片段文件并从索引移除

## Agentic-ready 接入设计

核心业务逻辑只写一份，通过不同接入适配层暴露给不同调用方：

- **程序内部**：直接调用 Python API（北向网关契约）
- **用户管理后台**：REST API
- **Agent / 外部 AI**：CLI

## 被引用方式

Agent 定义 YAML 中通过 `ref` 引用片段描述名：

```yaml
system_prompt:
  - ref: 业务架构设计规则
  - ref: 中文输出规范
  - text: |
      你是一个代码审查助手。
```

加载 Agent 定义时，调用本模块按 name 解析片段内容，拼接为完整系统提示词。
